## Pitch

« Life » : une simulation de particules 2D en JavaScript dans le navigateur, où des familles de particules colorées s'attirent ou se repoussent selon des règles (voir `index.html`, `main.js`).

<!-- builder:scope -->
## Périmètre

Aujourd'hui : une seule page, une animation canevas (WebGL 2, calcul dans un Web Worker, 20 000 particules) avec un compteur d'images par seconde, sans interaction, sans réglage ni sauvegarde. Voir la carte des capacités : `docs/product/capabilities/`. Le code non chargé (`mainbis.js`, `counter.js`, `gui.js` vide) est hors périmètre.
