# Carte des capacités

Un fichier Markdown par chose que le produit permet de faire. Frontmatter :

- `id` : identifiant stable de la forme `CAP-…`, en capitales, chiffres et tirets (par exemple `CAP-SIMULATION`) : App Builder refuse toute autre forme ;
- `title` : titre en français ;
- `parent` : `id` du groupe, lui aussi en `CAP-…` (vide pour un groupe de premier niveau).

Le corps décrit ce que la capacité fait pour l'utilisateur, ses règles, ses limites, et une ligne « Code : » vers les fichiers principaux.
