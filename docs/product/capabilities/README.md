# Carte des capacités

Un fichier Markdown par chose que le produit permet de faire. Frontmatter :

- `id` : identifiant stable, en kebab-case ;
- `title` : titre en français ;
- `parent` : `id` du groupe (vide pour un groupe de premier niveau).

Le corps décrit ce que la capacité fait pour l'utilisateur, ses règles, ses limites, et une ligne « Code : » vers les fichiers principaux.
